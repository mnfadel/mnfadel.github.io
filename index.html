MyAi is an AI assistant for companies that run Oracle Fusion Cloud ERP. Finance teams and managers ask about open invoices, aging, trial balances and cash, and get answers, tables and Excel files drawn live from their own Oracle data.

The problem

The answers are already in the ERP. Getting them out takes specialists.

Questions queue up

Someone has to know which screen or report to open, run it, export to Excel and reconcile. Managers wait on a small ERP and BI team, and month-end questions pile up.

Generic chatbots can’t reach the ERP safely

Connecting a general-purpose AI usually means a shared service account, which bypasses each person’s security.

A plausible wrong figure is worse than none

In finance, a number that merely looks right does real damage. Answers have to come from the ledger, not from a guess.

How it works

Built on Oracle’s own security, read-only by design

MyAi connects Anthropic’s Claude to Oracle Fusion for every person in the company, without widening anyone’s access.

1

Each person signs in as themselves

Through the company’s own identity domain (OAuth). There is no service account, so Oracle’s data security applies to every answer.

2

Read-only, always

MyAi can read, never change data, and never send, print or e-mail documents from Oracle.

3

Every query is checked

Queries are checked against Oracle’s API definitions before they run.

4

Answers rest on Oracle’s figures

Only figures Oracle returned make it into an answer. Gaps are stated, not filled.

For finance teams and their auditors

A security model large finance teams can accept

MyAi covers Financials in depth: Payables, Receivables, General Ledger and Cash Management. It runs Oracle’s standard reports and the company’s own BI Publisher reports through Oracle’s scheduler, as the person asking, with Excel and Oracle-layout output.

  • No shared or service account. Every person signs in to Oracle as themselves.
  • Oracle decides what each person sees. Its data security applies to every answer.
  • Read-only. No data changes, and nothing is sent, printed or e-mailed from Oracle.
  • Checked before it runs. Queries are validated against Oracle’s API definitions.
  • Accuracy gates. An evaluation suite and an automatic answer check guard every release and every answer.
